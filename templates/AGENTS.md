# 작업 원칙
- 실행 전에 방법과 만들거나 바꿀 파일을 먼저 보고하고, 승인 후 실행한다
- 한 번에 성공 기준 하나, 작업 하나만 한다
- 계산은 코드로 하고, 원문 숫자는 바꾸지 않는다
- 대상을 고를 때는 후보 목록 안에서만 고르고, 목록 밖이면 "후보 밖"이라고 표시한다
- 근거가 없으면 "모름"이라고 쓰고 추측하지 않는다
- 단순한 방법을 먼저 쓰고, 요청받지 않은 기능은 만들지 않는다
- 결과를 보고할 때는 사용한 조건(필터·기간)을 함께 적는다

# 기록
- git이 있으면 단계가 끝날 때마다 "무엇을 했고 핵심 결과" 메시지로 커밋한다
- git이 없으면 NOTES.md 맨 아래 "작업 기록"에 같은 형식으로 한 줄 추가한다
- 결정을 내리면 DECISIONS.md에 이유·버린 대안·한계를 적는다
