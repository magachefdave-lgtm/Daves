설비 원격 접속 - 시작하기
==========================

1. 처음 한 번
   - 이 폴더를 쓰기 가능한 곳(예: D:\Tools\설비원격접속)에 둡니다.
   - EquipmentRemote.exe 를 실행합니다.
   - [더보기 > 설정]을 눌러 VNC 뷰어 종류와 실행 파일을 지정합니다.
     ([자동]을 누르면 기본 위치에 설치된 TightVNC / UltraVNC / RealVNC / TigerVNC 를 찾습니다.)

2. 설비 등록
   - 한 대씩: [＋ 설비 추가]
   - 여러 대 한꺼번에: 설비목록_예시.csv 를 엑셀로 열어 고친 뒤 [더보기 > CSV 가져오기]
     첫 줄은 "설비명,그룹,IP,포트,OS,공유폴더,메모" 그대로 둡니다.
     설비명이 이미 있으면 그 설비의 내용을 고치고, 없으면 새로 추가합니다.
   - 수정/삭제: 설비 버튼의 [⋯] 또는 오른쪽 클릭 > 수정 / 삭제

3. 접속
   설비 한 대가 버튼 하나입니다. 그룹(라인)별로 묶여 보입니다.
   - VNC 접속   : 설비 버튼을 클릭합니다.
   - 공유폴더   : Windows 설비 버튼 안의 [공유폴더]를 클릭합니다. (Linux 설비에는 없습니다)
                  탐색기로 \IP\공유폴더 를 엽니다. 공유폴더 칸을 비워 둔 설비는 \IP 를 엽니다.
                  계정과 비밀번호는 Windows가 직접 묻습니다.
   - 상태       : 초록 점 = VNC 포트 응답 있음, 빨간 점 = 응답 없음.
                  [상태 확인] 또는 F5 로 다시 확인합니다.
   - 그룹       : 위쪽의 그룹 이름을 누르면 그 그룹만 보입니다.
   - 검색       : 설비명, 그룹, IP, 메모로 찾습니다. (Ctrl+F, Esc = 지우기)
                  한 대만 남았을 때 Enter 를 누르면 바로 접속합니다.
   - [⋯]        : VNC 접속, 공유폴더 열기, IP 복사, 수정, 삭제

4. 여러 PC가 같은 설비 목록 쓰기
   [더보기 > 설정] > 설비 목록 파일에 공유 폴더 경로를 넣습니다.
   예: \\서버\공유\equipment.json
   한 PC에서 추가/삭제하면 다른 PC 화면에도 몇 초 안에 반영됩니다.

5. VNC 비밀번호
   - 한꺼번에 넣기: 파일에 설비명과 비밀번호를 적어 [더보기 > CSV 가져오기]로 한 번 가져오면
     프로그램이 기억합니다. 그 뒤로는 파일이 없어도 되고, 접속할 때 자동으로 넣습니다.
       방법 1) 설비 목록 CSV 맨 끝에 "비밀번호" 열을 추가 (설비 등록과 동시에)
       방법 2) "설비명,비밀번호" 두 열만 있는 파일 (비밀번호_예시.csv 참고)
               이미 등록된 설비에 비밀번호만 붙입니다. 다른 정보는 바뀌지 않습니다.
     비밀번호 칸이 빈 줄은 기존에 기억한 비밀번호를 그대로 둡니다.
     비밀번호가 바뀌면 바뀐 설비만 적어 다시 가져오면 됩니다.
   - 한 대씩 넣기: 설비 버튼의 [⋯] > 수정 화면에서 입력합니다.
   - 가져온 파일에는 비밀번호가 그대로 적혀 있으므로, 가져온 뒤에는 안전한 곳에 두거나 지우세요.
   - 기억한 비밀번호는 설비 목록 파일이 아니라 이 PC의 passwords.json 에 Windows 계정으로
     암호화해 저장합니다. 다른 PC나 다른 계정에서는 풀리지 않으므로 PC마다 한 번씩 가져옵니다.
   - CSV 내보내기에는 비밀번호가 들어가지 않습니다.
   - 자동 입력은 TightVNC, UltraVNC 에서 됩니다. RealVNC, TigerVNC 는 실행 인자로 비밀번호를
     받지 않으므로 뷰어가 직접 묻습니다.
   - 접속하는 동안에는 비밀번호가 뷰어 프로그램의 실행 인자로 전달됩니다.

6. 파일
   config.ini      설정 (지우면 기본값으로 새로 만듭니다)
   equipment.json  설비 목록 (.bak = 직전 저장본)
   passwords.json  이 PC에 저장한 VNC 비밀번호 (암호화)

7. 문제가 생기면
   - "VNC 뷰어를 실행할 수 없습니다"  -> [더보기 > 설정]에서 뷰어 실행 파일 경로 확인
   - 켜져 있는데 "응답 없음"          -> 설비의 VNC 포트(기본 5900)와 방화벽 확인
   - 프로그램이 시작되지 않음         -> 폴더의 실행오류_안내.txt 를 담당자에게 전달
