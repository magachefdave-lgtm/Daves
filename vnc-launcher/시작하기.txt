설비 원격 접속 - 시작하기
==========================

1. 처음 한 번
   - EquipmentRemote.exe 파일 하나만 있으면 됩니다. 바탕화면, 내 폴더, 공유 폴더 어디서 실행해도 됩니다.
   - 처음 실행하면 "처음 설정" 창이 뜹니다. VNC 뷰어와 설비 목록 위치를 확인하고 [저장]을 누릅니다.
     ([자동]을 누르면 기본 위치에 설치된 TightVNC / UltraVNC / RealVNC / TigerVNC 를 찾습니다.)
     부서가 함께 쓰는 설비 목록이 있으면 '설비 목록 파일'에 그 경로를 넣습니다.
   - 나중에 바꾸려면 [더보기 > 설정]. 이 사용법은 [더보기 > 사용법 보기]로 언제든 볼 수 있습니다.

2. 설비 등록
   - 한 대씩: [＋ 설비 추가]
   - 여러 대 한꺼번에: [더보기 > CSV 양식 저장]으로 설비목록_예시.csv 를 받아 엑셀로 고친 뒤
     [더보기 > CSV 가져오기]
     첫 줄(열 이름)은 예시 파일 그대로 둡니다. 쓸 수 있는 열:
       설비명, 그룹, IP, 포트, OS, 공유폴더, 메모, 주의, 공유폴더사용, RDP사용, 상태확인, 비밀번호
     설비명과 IP 는 꼭 있어야 하고, 나머지 열은 필요한 것만 두면 됩니다.
     설비명이 이미 있으면 그 설비의 내용을 고치고, 없으면 새로 추가합니다.
     이미 있는 설비는 CSV 에 없는 열을 그대로 둡니다. (예: 메모 열이 없으면 메모는 안 바뀝니다)
     주의 열은 새로 추가하는 설비에만 씁니다. 이미 있는 설비의 주의 표시는 프로그램에서 바꿉니다.
     (예전에 내보낸 CSV 를 다시 가져와도 현장에서 붙인 "PM 중" 같은 표시가 지워지지 않게)
   - 수정/삭제: 설비 버튼을 오른쪽 클릭 > 수정 / 삭제

3. 접속
   설비 한 대가 버튼 하나입니다. 창 크기에 맞춰 한 화면에 다 보이도록 버튼 크기가 조절됩니다.
   - VNC 접속     : 설비 버튼을 클릭합니다.
                    이미 접속해 있는 설비를 다시 누르면 새로 접속하지 않고 그 창을 앞으로 가져옵니다.
   - 공유폴더     : Windows 설비 버튼 오른쪽의 폴더 아이콘을 클릭합니다.
                    탐색기로 \\IP\공유폴더 를 엽니다. 공유폴더 칸을 비워 둔 설비는 \\IP 를 엽니다.
                    계정과 비밀번호는 Windows가 직접 묻습니다.
   - 원격 데스크톱 : (켰을 때만) Windows 설비 버튼의 모니터 아이콘을 클릭합니다.
                    Windows 원격 데스크톱 연결(mstsc)로 접속하고, 계정은 Windows가 묻습니다.
                    켜기: [더보기 > 설정 > 원격 데스크톱(RDP) 버튼 사용]
   - 검색         : 설비명, 그룹, IP, 메모, 주의 표시로 찾습니다. (Ctrl+F, Esc = 지우기)
                    한 대만 남았을 때 Enter 를 누르면 바로 접속합니다.
   - 설비 정보    : 버튼에 마우스를 올리면 창 맨 아래에 IP, OS, 그룹, 주의 표시, 메모가 보입니다.
   - 오른쪽 클릭  : 접속, 공유폴더, IP 복사, 즐겨찾기, 주의 표시, 그룹 이동, 버튼 표시,
                    VNC 비밀번호 저장, 수정, 삭제, 여러 대 선택

   상태 표시 (창 오른쪽 아래에 범례)
     회색 버튼 + 녹색 점     = 정상 (VNC 포트 응답 있음)
     붉은 버튼 + 빨간 네모   = 응답 없음
     주황 버튼 + ▲          = 주의 표시가 있음 (PM 중 등)
     회색 버튼 + 빈 동그라미 = 아직 확인 안 됨
     옅은 파랑 + 움직이는 막대 = 접속 시도 중
     파란 버튼               = 지금 접속 중
   - 상태는 1분마다 저절로 다시 확인합니다. 그 사이 응답 없음으로 바뀐 설비가 있으면
     창 아래쪽에 이름이 나옵니다. 위쪽 바에 마지막으로 확인한 시각이 보입니다.
     간격 바꾸기·끄기: [더보기 > 설정 > 자동 상태 확인]. 바로 확인: [상태 확인] 또는 F5
   - 확인 방식 (설비 오른쪽 클릭 > 상태 확인, 또는 설비 수정 화면)
       자동      Windows 설비는 VNC 포트, Linux 설비는 ping 으로 확인 (기본)
       VNC 포트  VNC 포트에 연결해 봅니다
       ping      ping 응답만 봅니다. VNC 서버는 건드리지 않습니다
       하지 않음 상태를 확인하지 않습니다 (미확인으로 보입니다)
     리눅스 VNC 서버(TigerVNC, RealVNC 등)는 로그인 없이 끊긴 연결을 "보안 실패"로 세어, 5번이 쌓이면
     그 PC 의 접속을 막습니다("Too many security failures"). 그래서 리눅스는 VNC 포트 대신 ping 으로 확인합니다.
     OS 가 "기타"인 리눅스 설비는 OS 를 Linux 로 바꾸거나, 상태 확인을 ping 으로 바꾸세요.
     리눅스 설비를 "VNC 포트"로 바꾸려 하면 한 번 더 묻습니다.
   - ping 이 막힌 설비(접속은 되는데 늘 빨간색)는 상태 확인을 "하지 않음"으로 둡니다. 여러 대를 한 번에:
       위쪽 빨간 [응답 없음 N대] 누르기 → 빨간 설비만 보임 → 아무 설비나 Ctrl+클릭 → [모두 고르기]
       → [상태 확인 ▾] → 하지 않음.   (그룹 이름을 눌러 그 그룹만 보이게 한 뒤 해도 됩니다)
     바꾸면 바로 새 방식으로 다시 확인하고, "하지 않음"인 설비는 회색(미확인)으로 보입니다.
   - 응답 없는 설비가 있으면 위쪽에 빨간 "응답 없음 N대"가 나타나고,
     누르면 그 설비만 보입니다. 다시 누르면 전체로 돌아갑니다.

   접속 시도 중 · 접속 중
   - 설비 버튼을 누르면 옅은 파란색으로 바뀌고, 창 오른쪽 위에 "접속 시도 중… 설비명"이 나옵니다.
   - 뷰어 창이 화면에 뜨면 "접속 중"(진한 파랑)으로 바뀝니다. 창을 닫으면 표시가 사라집니다.
   - 뷰어가 창을 띄우지 못하고 닫히면 아래쪽에 "접속하지 못했습니다"가 나옵니다.
   - VNC 창의 제목 표시줄 앞에 [설비명] 이 붙습니다. (끄기: 더보기 > 설정)

   접속 도중 뜨는 창 없애기
   - 비밀번호 입력창: 설비 비밀번호를 저장해 두면 뜨지 않습니다. (9. VNC 비밀번호 참고)
     저장하지 않은 설비나 비밀번호가 틀린 설비는 뷰어가 묻습니다.
   - "연결 중" 상태창: 더보기 > 설정 > "접속 도중 뜨는 상태창 숨기기" (기본 켜짐, UltraVNC 에 적용)
   - 접속에 실패했을 때 뜨는 오류 창은 숨기지 않습니다.
   - RealVNC, TigerVNC 는 비밀번호를 넘겨받지 않으므로 비밀번호 입력창을 없앨 수 없습니다.

4. 즐겨찾기
   - 맨 위 "★ 즐겨찾기" 줄에 즐겨찾기한 설비가 모두 나옵니다.
   - 넣기/빼기: 설비 버튼 오른쪽 클릭 > 즐겨찾기에 넣기 / 즐겨찾기에서 빼기
   - 이 줄은 [전체]를 볼 때만 나옵니다. (검색 중이거나 그룹을 고르면 숨깁니다)
   - 즐겨찾기는 PC마다 따로 기억합니다. (다른 사람 화면에는 영향 없음)

5. 주의 표시 (PM 중, 점검 중, 고장, 접속 금지 등)
   - 설비 버튼 오른쪽 클릭 > 주의 표시 > 고르거나 [직접 입력]. 지우기도 같은 곳에서.
   - 표시한 설비는 주황색 버튼에 ▲ 가 붙고, 접속할 때 한 번 더 묻습니다.
   - 주의 표시는 설비 목록에 저장되므로, 목록을 함께 쓰는 모든 PC에 보입니다.
   - 편집 잠금이 걸려 있어도 PIN 없이 표시하고 지울 수 있습니다.

6. 여러 대 한꺼번에
   - Ctrl 을 누른 채 설비 버튼을 클릭하면 "여러 대 선택"이 시작됩니다.
     (또는 오른쪽 클릭 > 여러 대 선택하기, 더보기 > 여러 대 선택하기)
   - 선택하는 동안에는 클릭 = 고르기/빼기, Shift+클릭 = 범위 고르기 입니다. (접속하지 않습니다)
   - 아래쪽 바에서: [그룹 ▾] 그룹 이동, [주의 ▾] 주의 표시, [상태 확인 ▾], 즐겨찾기, 삭제,
     [모두 고르기](지금 보이는 설비 전부)
     고른 설비를 오른쪽 클릭해도 같은 메뉴가 나옵니다. Delete 키 = 삭제
   - 끝내기: [끝내기] 또는 Esc  (검색어가 있으면 첫 Esc 는 검색어만 지웁니다)

7. 그룹
   - 위쪽의 그룹 이름을 누르면 그 그룹만 보입니다. 마지막으로 본 그룹은 다음에 켤 때도 그대로입니다.
   - 그룹 만들기/이름 변경/삭제/순서 바꾸기: [＋ 그룹 관리]
     왼쪽에서 그룹을 고르고 오른쪽 목록에서 설비를 클릭하면 그 그룹에 들어갑니다.
     [저장]을 눌러야 반영됩니다. 그룹을 삭제해도 설비는 "그룹 없음"으로 옮겨질 뿐 지워지지 않습니다.
   - 한 대씩 옮기기: 설비 버튼 오른쪽 클릭 > 그룹 이동 (새 그룹도 여기서 만들 수 있습니다)
   - 여러 대 옮기기: 6. 여러 대 한꺼번에

8. 버튼 표시 (공유폴더 · 원격 데스크톱 아이콘)
   - 설비 하나만: 설비 버튼 오른쪽 클릭 > 버튼 표시 > 공유폴더 버튼 / 원격 데스크톱 버튼
     또는 수정 화면의 "버튼 표시" 체크
   - 전부: 더보기 > 설정 > "공유폴더 버튼 사용" / "원격 데스크톱(RDP) 버튼 사용"
   - CSV 로 한꺼번에: "공유폴더사용", "RDP사용" 열에 Y 또는 N

9. VNC 비밀번호
   - 한꺼번에 넣기: 파일에 설비명과 비밀번호를 적어 [더보기 > CSV 가져오기]로 한 번 가져오면
     프로그램이 기억합니다. 그 뒤로는 파일이 없어도 되고, 접속할 때 자동으로 넣습니다.
       방법 1) 설비 목록 CSV 맨 끝에 "비밀번호" 열을 추가 (설비 등록과 동시에)
       방법 2) "설비명,비밀번호" 두 열만 있는 파일 (비밀번호_예시.csv 참고)
               이미 등록된 설비에 비밀번호만 붙입니다. 다른 정보는 바뀌지 않습니다.
     비밀번호 칸이 빈 줄은 기존에 기억한 비밀번호를 그대로 둡니다.
   - 한 대씩 넣기: 설비 버튼 오른쪽 클릭 > VNC 비밀번호 저장
   - 가져온 파일에는 비밀번호가 그대로 적혀 있으므로, 가져온 뒤에는 안전한 곳에 두거나 지우세요.
   - 기억한 비밀번호는 설비 목록 파일이 아니라 이 PC의 passwords.json 에 Windows 계정으로
     암호화해 저장합니다. 다른 PC나 다른 계정에서는 풀리지 않으므로 PC마다 한 번씩 넣습니다.
   - CSV 내보내기에는 비밀번호가 들어가지 않습니다.
   - 자동 입력은 TightVNC, UltraVNC 에서 됩니다. RealVNC, TigerVNC 는 뷰어가 직접 묻습니다.
   - 접속하는 동안에는 비밀번호가 뷰어 프로그램의 실행 인자로 전달됩니다.

10. 여러 PC가 같은 설비 목록 쓰기
   [더보기 > 설정] > 설비 목록 파일에 공유 폴더 경로를 넣습니다.
   예: \\서버\공유\equipment.json
   한 PC에서 추가/삭제하면 다른 PC 화면에도 몇 초 안에 반영됩니다.
   주의 표시와 편집 잠금도 함께 적용됩니다. 즐겨찾기·창 위치·비밀번호는 PC마다 따로입니다.
   ※ 같은 목록을 쓰는 PC는 모두 이 버전으로 바꾼 뒤 편집 잠금·주의 표시를 쓰세요.
     예전 버전 PC에서 설비를 추가·수정하면 편집 잠금, 주의 표시, 원격 데스크톱 버튼 설정이 지워집니다.

11. 편집 잠금 (관리자 PIN)
   - 실수로 설비나 그룹을 지우는 일을 막습니다. [더보기 > 편집 잠금 설정]에서 PIN 을 정합니다.
     PIN 은 영문·숫자로 정합니다. 한/영 키가 한글 상태면 받지 않습니다.
   - 잠그면 설비 추가·수정·삭제, 그룹 변경, 버튼 표시 변경, 설비 목록 CSV 가져오기 때 PIN 을 묻습니다.
     접속, 주의 표시, 즐겨찾기, 비밀번호 저장은 PIN 없이 됩니다.
   - 한 번 PIN 을 넣으면 30분 동안 편집하지 않을 때까지 다시 묻지 않습니다.
     위쪽 바에 "편집 잠금 풀림"이 보이는 동안입니다. 바로 잠그기: [더보기 > 편집 다시 잠그기]
   - PIN 은 설비 목록 파일에 (풀 수 없는 형태로) 저장되어, 목록을 함께 쓰는 모든 PC에 적용됩니다.
   - PIN 을 잊었으면: 명령 프롬프트에서  EquipmentRemote.exe --reset-pin  을 실행하면 잠금이 꺼집니다.
     (설비 목록은 그대로이고, 끄기 전 상태는 backup 폴더에 남습니다)

12. 접속 이력 · 백업
   - 접속 이력: 언제, 어느 PC에서, 누가, 어느 설비에 접속했는지 남깁니다.
     설비 목록 파일과 같은 폴더에 달마다 "접속이력_2026-11.csv" 처럼 쌓입니다.
     보기: [더보기 > 접속 이력 보기] (엑셀로 복사본을 열어, 보는 동안에도 이력이 계속 남습니다)
     끄기: [더보기 > 설정 > 접속 이력 남기기]
   - 백업: 설비 목록을 바꾸는 날마다, 그날 처음 바꾸기 직전 상태를
     설비 목록 파일 옆 backup 폴더에 날짜별로 남깁니다. (14일치 보관)
     되돌리려면 backup 폴더의 파일을 equipment.json 으로 이름을 바꿔 덮어씁니다.
     열기: [더보기 > 백업 폴더 열기]

13. 파일
   프로그램은 EquipmentRemote.exe 하나입니다. 사용법과 CSV 양식도 그 안에 들어 있습니다.
   사람마다 따로 남는 것은 설정 폴더 %LOCALAPPDATA%\설비원격접속 에 있습니다. ([더보기 > 설정 폴더 열기])
     config.ini      설정 (지우면 다음 실행 때 "처음 설정"부터 다시 합니다)
     passwords.json  이 PC·이 계정에 저장한 VNC 비밀번호 (암호화)
     ui_state.json   즐겨찾기, 창 크기·위치, 마지막으로 본 그룹
     equipment.json  설비 목록 (공유 목록 경로를 정하지 않았을 때만 여기에)
   설비 목록 파일 옆에 남는 것:
     equipment.json.bak  직전 저장본,  backup 폴더  날짜별 백업,  접속이력_*.csv  접속 이력
   ※ 예전 버전처럼 exe 옆에 config.ini 가 있으면 그 폴더를 설정 폴더로 그대로 씁니다.

14. 부서에 배포하기 (관리자)
   - 공유 폴더에 설비 목록을 하나 정합니다. 예: \\서버\설비팀\원격접속\equipment.json
     한 사람이 그 경로로 설정한 뒤 설비를 등록하거나 CSV 로 가져옵니다. 필요하면 편집 잠금 PIN 도 정합니다.
   - EquipmentRemote.exe 하나를 메신저·메일·공유 폴더로 나눠 줍니다.
     받은 사람은 실행 후 "처음 설정"에서 설비 목록 파일에 위 경로를 넣고 [저장]하면 끝입니다.
   - 더 쉽게: [더보기 > 배포본 만들기]
     지금 내 PC의 설정, 설비 목록(또는 공유 목록 경로), VNC 비밀번호를 넣은 exe 를 따로 만듭니다.
     받은 사람은 그 exe 를 실행만 하면 같은 상태로 시작합니다. (설정할 것이 없습니다)
     · 비밀번호를 넣을 때는 "배포 암호"를 정하는 것을 권합니다. 받은 사람이 처음 실행할 때 한 번 묻고,
       맞으면 비밀번호를 그 사람 PC에 저장합니다. 배포 암호는 exe 와 따로(말이나 메신저로) 알려 주세요.
     · 배포 암호 없이 만들면 그 exe 를 가진 사람은 누구나 비밀번호를 꺼낼 수 있습니다.
     · 이미 쓰고 있는 사람이 배포본을 실행하면 가져올지 묻고, 설비는 합치고 즐겨찾기는 그대로 둡니다.
     · 편집 잠금이 걸려 있으면 배포본을 만들 때 PIN 을 묻습니다.
   - 공유 폴더에 exe 를 두고 거기서 바로 실행해도 됩니다. 설정은 사람마다 따로 저장됩니다.
   - 새 버전을 배포할 때는 exe 만 바꿔 주면 됩니다. 설정·즐겨찾기·비밀번호는 그대로입니다.
     같은 목록을 쓰는 사람은 모두 같은 버전으로 바꿔 주세요. (10번의 ※ 참고)
   - 인터넷에서 받은 exe 는 Windows 가 "PC 보호" 창을 띄울 수 있습니다. [추가 정보 > 실행]을 누르면 됩니다.
     회사 보안 프로그램이 막으면 보안 담당자에게 예외 등록을 요청하세요.

15. 업데이트
   - 새 버전이 서버에 올라오면, 프로그램을 켤 때 위쪽에 파란 [업데이트 v1.x.x] 버튼이 나타납니다.
     누르면 바뀐 점을 보여 주고, [예]를 누르면 새 버전을 받아 바꾼 뒤 저절로 다시 켜집니다.
     설정·즐겨찾기·비밀번호·설비 목록은 그대로입니다. 열려 있는 VNC 창도 그대로 둡니다.
   - 직접 확인: [더보기 > 업데이트 확인]
   - 업데이트 폴더는 [더보기 > 설정 > 업데이트 폴더]에 적힌 서버 폴더입니다. 비어 있으면 확인하지 않습니다.
   - exe 를 둔 폴더에 쓸 수 없으면(예: 다른 사람 공유 폴더) 새 버전을 설정 폴더에 받고 그 위치를 알려 줍니다.

   관리자: 새 버전 올리기
   1) 새 버전 EquipmentRemote.exe 를 받아 한 번 실행합니다. (창 제목에 새 버전 번호가 보입니다)
   2) [더보기 > 설정]에서 업데이트 폴더를 정합니다. 예: \\서버\설비팀\원격접속\update
      부서원 모두가 읽을 수 있고, 관리자는 쓸 수 있는 폴더여야 합니다.
   3) [더보기 > 업데이트 올리기] → 바뀐 점을 적고 [확인]. 폴더에 EquipmentRemote.exe 와 latest.json 이 생깁니다.
   - 편집 잠금이 걸려 있으면 올릴 때 PIN 을 묻습니다.
   - 서버에 있는 것보다 낮거나 같은 버전을 올리면 한 번 더 묻습니다. (받는 PC는 새 버전일 때만 업데이트합니다)
   - 배포본 exe 로 올려도 붙어 있는 설정·비밀번호는 떼고 프로그램만 올립니다.
   - 부서원에게 처음 나눠 줄 때 업데이트 폴더까지 넣어 두려면 [더보기 > 배포본 만들기]를 쓰세요.
     (배포본에는 지금 설정이 들어가므로 업데이트 폴더도 함께 들어갑니다)

16. 문제가 생기면
   - "VNC 뷰어를 실행할 수 없습니다"  -> [더보기 > 설정]에서 뷰어 실행 파일 경로 확인
   - 켜져 있는데 "응답 없음"          -> 설비의 VNC 포트(기본 5900)와 방화벽 확인
                                         (ping 으로 확인하는 설비는 설비의 ping 응답이 막혀 있지 않은지)
   - 리눅스 설비에서 "Too many security failures"
                                      -> 설비의 OS 가 Linux 인지, 상태 확인이 "자동" 또는 "ping"인지 확인.
                                         이미 막혀 있으면 설비에서 VNC 서버를 다시 시작하거나 잠시 기다립니다.
                                         같은 설비를 쓰는 모든 PC가 1.4.1 이상이어야 합니다 (예전 버전이 계속 두드림).
   - 창이 화면 밖에 있음              -> 설정 폴더의 ui_state.json 을 지우고 다시 실행
   - 업데이트 버튼이 안 보임           -> [더보기 > 업데이트 확인]으로 오류 내용 확인 (폴더 경로·권한)
   - 프로그램이 시작되지 않음         -> 설정 폴더의 실행오류_안내.txt 를 담당자에게 전달
                                         (오류 창에 파일 위치가 나옵니다)
