설비 원격 접속 - 시작하기
==========================

1. 처음 한 번
   - 이 폴더를 쓰기 가능한 곳(예: D:\Tools\설비원격접속)에 둡니다.
   - EquipmentRemote.exe 를 실행합니다.
   - [설정]을 눌러 VNC 뷰어 종류와 실행 파일을 지정합니다.
     ([자동]을 누르면 기본 위치에 설치된 TightVNC / UltraVNC / RealVNC / TigerVNC 를 찾습니다.)

2. 설비 등록
   - 한 대씩: [설비 추가]
   - 여러 대 한꺼번에: 설비목록_예시.csv 를 엑셀로 열어 고친 뒤 [CSV 가져오기]
     첫 줄은 "설비명,그룹,IP,포트,OS,공유폴더,메모" 그대로 둡니다.
     설비명이 이미 있으면 그 설비의 내용을 고치고, 없으면 새로 추가합니다.
   - 설비가 없어지면 선택하고 [삭제] (여러 대 선택 가능: Ctrl/Shift + 클릭)

3. 접속
   - VNC 접속   : 설비를 더블클릭하거나 선택 후 [VNC 접속] (Enter)
   - 공유폴더   : Windows 설비를 선택하면 [공유폴더 열기]가 켜집니다.
                  탐색기로 \\IP\공유폴더 를 엽니다. 공유폴더 칸을 비워 둔 설비는 \\IP 를 엽니다.
                  계정과 비밀번호는 Windows가 직접 묻습니다.
   - 상태       : 초록 = VNC 포트 응답 있음, 빨강 = 응답 없음. [상태 확인] 또는 F5 로 다시 확인합니다.
   - 검색       : 설비명, 그룹, IP, 메모로 찾습니다. (Ctrl+F, Esc = 지우기)
   - 오른쪽 클릭: IP 복사 등

4. 여러 PC가 같은 설비 목록 쓰기
   [설정] > 설비 목록 파일에 공유 폴더 경로를 넣습니다.
   예: \\서버\공유\equipment.json
   한 PC에서 추가/삭제하면 다른 PC 화면에도 몇 초 안에 반영됩니다.

5. VNC 비밀번호
   - 설비 수정 화면에서 입력해 두면 접속할 때 자동으로 넣습니다. (TightVNC, UltraVNC)
   - 비밀번호는 설비 목록 파일이 아니라 이 PC의 passwords.json 에 Windows 계정으로
     암호화해 저장합니다. 다른 PC나 다른 계정에서는 풀리지 않으므로 PC마다 한 번씩 입력합니다.
   - 접속하는 동안에는 뷰어 프로그램의 실행 인자로 전달됩니다. 공용 PC라면 저장하지 말고
     뷰어가 물을 때 직접 입력하세요.
   - RealVNC, TigerVNC 는 실행 인자로 비밀번호를 받지 않으므로 뷰어가 직접 묻습니다.

6. 파일
   config.ini      설정 (지우면 기본값으로 새로 만듭니다)
   equipment.json  설비 목록 (.bak = 직전 저장본)
   passwords.json  이 PC에 저장한 VNC 비밀번호 (암호화)

7. 문제가 생기면
   - "VNC 뷰어를 실행할 수 없습니다"  -> [설정]에서 뷰어 실행 파일 경로 확인
   - 켜져 있는데 "응답 없음"          -> 설비의 VNC 포트(기본 5900)와 방화벽 확인
   - 프로그램이 시작되지 않음         -> 폴더의 실행오류_안내.txt 를 담당자에게 전달
