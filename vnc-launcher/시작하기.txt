설비 원격 접속 - 시작하기
==========================

1. 처음 한 번
   - 이 폴더를 쓰기 가능한 곳(예: D:\Tools\설비원격접속)에 둡니다.
   - EquipmentRemote.exe 를 실행합니다.
   - [더보기 > 설정]을 눌러 VNC 뷰어 종류와 실행 파일을 지정합니다.
     ([자동]을 누르면 기본 위치에 설치된 TightVNC / UltraVNC / RealVNC / TigerVNC 를 찾습니다.)

2. 설비 등록
   - 한 대씩: [＋ 설비 추가]
   - 여러 대 한꺼번에: 설비목록_예시.csv 를 엑셀로 열어 고친 뒤 [더보기 > CSV 가져오기]
     첫 줄은 "설비명,그룹,IP,포트,OS,공유폴더,메모" 그대로 둡니다.
     설비명이 이미 있으면 그 설비의 내용을 고치고, 없으면 새로 추가합니다.
   - 수정/삭제: 설비 버튼을 오른쪽 클릭 > 수정 / 삭제

3. 접속
   설비 한 대가 버튼 하나입니다. 창 크기에 맞춰 한 화면에 다 보이도록 버튼 폭이 조절됩니다.
   - VNC 접속   : 설비 버튼을 클릭합니다.
   - 공유폴더   : Windows 설비 버튼 오른쪽의 폴더 아이콘을 클릭합니다. (Linux 설비에는 없습니다)
                  탐색기로 \IP\공유폴더 를 엽니다. 공유폴더 칸을 비워 둔 설비는 \IP 를 엽니다.
                  계정과 비밀번호는 Windows가 직접 묻습니다.
   - 상태       : 버튼 색과 왼쪽 표시로 구분합니다. (창 오른쪽 아래에 범례)
                    회색 버튼 + 녹색 점   = 정상 (VNC 포트 응답 있음)
                    붉은 버튼 + 빨간 네모 = 응답 없음
                    회색 버튼 + 빈 동그라미 = 아직 확인 안 됨
                    파란 버튼             = 지금 접속 중
                  응답 없는 설비가 있으면 위쪽에 빨간 "응답 없음 N대"가 나타나고,
                  누르면 그 설비만 보입니다. 다시 누르면 전체로 돌아갑니다.
                  [상태 확인] 또는 F5 로 다시 확인합니다.
   - 설비 정보  : 버튼에 마우스를 올리면 창 맨 아래에 IP, OS, 그룹, 메모가 보입니다.
   - 검색       : 설비명, 그룹, IP, 메모로 찾습니다. (Ctrl+F, Esc = 지우기)
                  한 대만 남았을 때 Enter 를 누르면 바로 접속합니다.
   - 오른쪽 클릭: VNC 접속, 공유폴더 열기, IP 복사, 그룹 이동, 수정, 삭제

   접속 시도 중 표시
   - 설비 버튼을 누르면 그 버튼이 옅은 파란색으로 바뀌고 아래쪽에 막대가 좌우로 움직입니다.
     창 오른쪽 위에도 "접속 시도 중… 설비명"이 나옵니다.
   - 뷰어 창이 화면에 뜨면 "접속 중"(진한 파랑)으로 바뀝니다.
   - 뷰어가 창을 띄우지 못하고 닫히면 아래쪽에 "접속하지 못했습니다"가 나옵니다.

   접속 중인 설비
   - 창 오른쪽 위에 지금 VNC로 접속해 있는 설비명이 나오고, 그 설비 버튼은 파란색이 됩니다.
     뷰어 창을 닫으면 사라집니다.
   - VNC 창의 제목 표시줄 앞에 [설비명] 이 붙습니다. (끄기: 더보기 > 설정)

   접속 도중 뜨는 창 없애기
   - 비밀번호 입력창: 설비 비밀번호를 저장해 두면 뜨지 않습니다. (5. VNC 비밀번호 참고)
     저장하지 않은 설비나 비밀번호가 틀린 설비는 뷰어가 묻습니다.
   - "연결 중" 상태창: 더보기 > 설정 > "접속 도중 뜨는 상태창 숨기기" (기본 켜짐, UltraVNC 에 적용)
   - 접속에 실패했을 때 뜨는 오류 창은 숨기지 않습니다.
   - RealVNC, TigerVNC 는 비밀번호를 넘겨받지 않으므로 비밀번호 입력창을 없앨 수 없습니다.

   공유폴더 버튼 없애기
   - 설비 하나만: 설비 버튼 오른쪽 클릭 > 공유폴더 버튼 숨기기 (다시 보이기도 같은 곳)
     또는 수정 화면의 "이 설비에 공유폴더 버튼 보이기" 체크를 끕니다.
   - 전부: 더보기 > 설정 > "공유폴더 버튼 사용" 체크를 끕니다.
   - CSV 로 한꺼번에: "공유폴더사용" 열에 N 을 적습니다. (열이 없으면 기존 설정 유지)

   그룹
   - 위쪽의 그룹 이름을 누르면 그 그룹만 보입니다.
   - 그룹 만들기/이름 변경/삭제/순서 바꾸기: [＋ 그룹 관리]
     왼쪽에서 그룹을 고르고 오른쪽 목록에서 설비를 클릭하면 그 그룹에 들어갑니다.
     여러 대를 한 번에 정리할 때 씁니다. [저장]을 눌러야 반영됩니다.
     그룹을 삭제해도 설비는 삭제되지 않고 "그룹 없음"으로 옮겨집니다.
   - 한 대만 옮기기: 설비 버튼 오른쪽 클릭 > 그룹 이동 (새 그룹도 여기서 만들 수 있습니다)

4. 여러 PC가 같은 설비 목록 쓰기
   [더보기 > 설정] > 설비 목록 파일에 공유 폴더 경로를 넣습니다.
   예: \\서버\공유\equipment.json
   한 PC에서 추가/삭제하면 다른 PC 화면에도 몇 초 안에 반영됩니다.

5. VNC 비밀번호
   - 한꺼번에 넣기: 파일에 설비명과 비밀번호를 적어 [더보기 > CSV 가져오기]로 한 번 가져오면
     프로그램이 기억합니다. 그 뒤로는 파일이 없어도 되고, 접속할 때 자동으로 넣습니다.
       방법 1) 설비 목록 CSV 맨 끝에 "비밀번호" 열을 추가 (설비 등록과 동시에)
       방법 2) "설비명,비밀번호" 두 열만 있는 파일 (비밀번호_예시.csv 참고)
               이미 등록된 설비에 비밀번호만 붙입니다. 다른 정보는 바뀌지 않습니다.
     비밀번호 칸이 빈 줄은 기존에 기억한 비밀번호를 그대로 둡니다.
     비밀번호가 바뀌면 바뀐 설비만 적어 다시 가져오면 됩니다.
   - 한 대씩 넣기: 설비 버튼 오른쪽 클릭 > 수정 화면에서 입력합니다.
   - 가져온 파일에는 비밀번호가 그대로 적혀 있으므로, 가져온 뒤에는 안전한 곳에 두거나 지우세요.
   - 기억한 비밀번호는 설비 목록 파일이 아니라 이 PC의 passwords.json 에 Windows 계정으로
     암호화해 저장합니다. 다른 PC나 다른 계정에서는 풀리지 않으므로 PC마다 한 번씩 가져옵니다.
   - CSV 내보내기에는 비밀번호가 들어가지 않습니다.
   - 자동 입력은 TightVNC, UltraVNC 에서 됩니다. RealVNC, TigerVNC 는 실행 인자로 비밀번호를
     받지 않으므로 뷰어가 직접 묻습니다.
   - 접속하는 동안에는 비밀번호가 뷰어 프로그램의 실행 인자로 전달됩니다.

6. 파일
   config.ini      설정 (지우면 기본값으로 새로 만듭니다)
   equipment.json  설비 목록 (.bak = 직전 저장본)
   passwords.json  이 PC에 저장한 VNC 비밀번호 (암호화)

7. 문제가 생기면
   - "VNC 뷰어를 실행할 수 없습니다"  -> [더보기 > 설정]에서 뷰어 실행 파일 경로 확인
   - 켜져 있는데 "응답 없음"          -> 설비의 VNC 포트(기본 5900)와 방화벽 확인
   - 프로그램이 시작되지 않음         -> 폴더의 실행오류_안내.txt 를 담당자에게 전달
