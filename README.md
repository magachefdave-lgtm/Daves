# AI 활용 역량 평가 단계별 프롬프트

웹 IDE + 터미널 AI 코딩 도구 + 가상 업무 담당자 채팅 형식의 AI 활용 역량 평가(예: Cofa-Probe 방식)를 대비해 정리한 개인 준비 노트입니다. 공식 자료가 아니며, 실제 시험 규정이 항상 우선합니다.

## 풀이 순서 (4시간 기준)

| 단계 | 시간 | 남길 것 |
| --- | --- | --- |
| 1. 정찰 | 0:00–0:10 | NOTES.md: 요청·제출물·모르는 것 |
| 2. 담당자 인터뷰 | 0:10–0:30 | NOTES.md: 인터뷰 메모 |
| 3. 서면 합의 | 0:30–0:40 | AGENTS.md |
| 4. 데이터화 | 0:40–1:10 | 정리된 표, 기준표 |
| 5. 분석 | 1:10–2:30 | 결과 표 |
| 6. 검증 | 2:30–3:05 | 비교표, 담당자 확인 |
| 7. 문서화·제출 | 3:05–3:35 | REPORT.md, DECISIONS.md |
| 8. 확인 질문 | 제출 후 | AI 없이 3줄 답 |

## 파일

- [prompts.md](prompts.md): 단계별로 그대로 쓰는 프롬프트
- [templates/AGENTS.md](templates/AGENTS.md): AI가 매번 읽는 목표·원칙 파일
- [templates/NOTES.md](templates/NOTES.md): 정찰·인터뷰·작업 기록
- [templates/DECISIONS.md](templates/DECISIONS.md): 판단 기록
- [templates/REPORT.md](templates/REPORT.md): 결과 요약

## 핵심 원칙

1. 맡기고, 확인하고, 기록한다.
2. 한 질문에 한 작업. 대상을 고를 때는 후보 목록 안에서만.
3. 원문을 먼저 표로 바꾸고, 계산은 코드로, 판단은 직접.
4. 단순한 방법 먼저. 요청받지 않은 기능은 만들지 않는다.
5. 하지 않은 일은 문서에 적지 않는다.
